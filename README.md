# Research

## Fast Classifiers of Signals from Nanopore Sequencing Reads

My M.Tech research focuses on **early classification of nanopore sequencing signals for adaptive sampling in precision oncology**.

The goal is to determine whether a sequencing read belongs to a target genomic region **before processing the entire signal**.

### Core Pipeline

```text
Raw Nanopore Signal
        │
        ▼
Signal Preprocessing
        │
        ▼
Convolutional Feature Extraction
        │
        ▼
Dilated Convolution
        │
        ▼
Bidirectional GRU
        │
        ▼
Squeeze-and-Excitation
        │
        ▼
Early Classification
        │
        ▼
Target / Non-Target
```

### Research Areas

* Nanopore sequencing
* Signal processing
* Time-series classification
* CNN architectures
* GRU / BiGRU
* Attention mechanisms
* Wavelet transforms
* Early-exit neural networks
* Confidence calibration
* Domain shift
* Efficient inference
